Control an LED remotely over Wi-Fi using NodeMCU ESP8266 and the KiwisIoT platform for simple real-time IoT control.
Smart LED Monitoring and Control Using KiwisIoT

📌 About the Project

Smart LED Monitoring and Control Using KiwisIoT is an IoT-based smart lighting project designed to remotely monitor and control LED lights through an online platform.

Using a microcontroller and a connected LED control circuit, the system allows users to switch LED lights ON and OFF remotely through the KiwisIoT platform.

The device connects to the internet through Wi-Fi and communicates with the KiwisIoT platform, allowing users to control LED status and monitor connected lighting devices through an online dashboard.

This project demonstrates how IoT technology can support smart lighting automation, remote device management, energy-efficient lighting, and intelligent home automation.
